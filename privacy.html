アプリ紹介プライバシー利用条件

プライバシーポリシー

利用目的と取得範囲

アカウント所有者のメール情報整理のため、Gmail のラベルやヘッダーなどのメタデータを取得します。現在の接続スコープは gmail.metadata です。

処理と保存

OAuth 認証情報は n8n Cloud で管理します。取得した情報は n8n Cloud のワークフロー内で処理します。手動実行と本番実行の履歴を保存する設定のため、API 応答が実行履歴に含まれることがあります。履歴は n8n Cloud の保持設定に従って削除されます。

外部サービス

Google と n8n Cloud を利用します。この連携の利用目的はアカウント所有者本人の情報整理です。このウェブサイトは Gmail データを取得する機能を持ちません。

アクセスの解除と削除

Google アカウントの接続済みアプリ管理からアクセスを取り消せます。アカウント所有者は n8n の実行履歴から保存済みの実行データを削除できます。

連絡先

この連携に関する問い合わせは、Google の OAuth 同意画面に表示されるサポート連絡先をご利用ください。
